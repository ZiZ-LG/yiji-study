# 易记

> **0.2.0** 新增自定义题库、资料核对、组卷和间隔巩固。[查看更新说明](./docs/releases/0.2.0.md)。

[English documentation](./README.md)

“易记”是一个本地优先的 Obsidian 刷题插件。支持自定义题库、资料导入、AI 辅助整理、核对入库、组卷和间隔巩固流程。首版支持单选、多选、判断；其他题型保留为待处理内容。

手工建题、标准格式导入、刷题判题和复习排程在本地完成。选择 AI 服务时，插件只在用户发起处理后发送选定内容；也可以导出 Codex 文件任务，再把结果导回核对。

## 安装公开稳定版

在 Obsidian 中依次打开“设置 → 第三方插件 → 浏览”，搜索 **Yiji Study** 并安装；已安装用户可在第三方插件中检查更新。社区目录名称为 “Yiji Study”，插件内沿用中文名称“易记”。

项目仅维护 Obsidian 社区插件的安装与自动更新渠道。可打开[易记社区插件页](https://obsidian.md/plugins?id=yiji-study)，或在 Obsidian 中搜索 **Yiji Study**。

升级前保留仓库备份。手动更新只替换插件文件，保留原 data.json 和题库目录。

## 从自己的资料开始刷题

1. 通过功能区书本图标打开易记，进入题库管理；也可在命令面板运行“管理题库与导入资料”。新用户从空白“我的题库”开始，可自行添加内置电力题库。
2. 新建或切换题库。可以手工新增题目、粘贴文本或选择本地资料。题卷与独立答案文件需填写相同卷名，并分别选择“题卷／题库”和“答案文件”角色。
3. 检查本地读取结果。需要 AI 整理时，勾选具体页面或段落，查看范围并确认；未选资料不加入该次请求或导出的任务。
4. 在“导入核对”中对照原文。普通题可抽查后批量采用；缺答案、答案冲突、缺图及其他问题题需逐题处理。确认入库表示采用当前内容，不代表系统已查证为官方答案。
5. 返回题库，按知识点或题型刷题，也可练错题、收藏题和未答题。作答、错题和断点在本地保存。
6. 需要整卷训练时，保存原卷或按条件组合试卷；需要间隔后再检查时，为当前题库开启“巩固复习”。

## 可以导入哪些资料

| 格式 | 处理方式 |
|---|---|
| 文本 PDF | 本地提取文字并保留原页预览；每批选择最多 50 页，长卷可再次导入同一文件的后续范围，累计保留已完成页 |
| Word `.docx` | 本地读取正文、常见表格和支持的内嵌图片；复杂排版、缺图等情况仍需核对 |
| 扫描 PDF、PNG、JPEG | 保留原页／图片；识别需使用支持图像的 AI 服务，或让 Codex 处理导出任务中的选定图片 |
| TXT、Markdown、CSV、题库 JSON | 对支持的结构进行本地解析；不规则文本可再交给 AI 整理 |

当前单文件上限为 50 MB，一次 AI 整理最多选择 50 个页面或资料段落。老式 `.doc`、`.xlsx` 和压缩包不直接转换为可用题库。公式、多栏、跨页题和复杂图表可能需要人工校正。

“文件已接收”或“文字提取成功”不等于原卷已完整还原。核对页保留识别问题和未处理范围；整页预览可能包含答案，不会自动当作答题页的题图。

手机界面提供文件选择、小批量核对与组卷入口；Android 模拟器核心流程已验收；iOS 由发布负责人手动验收通过。长卷整理和原文对照建议先在桌面完成。

## AI 的两种使用方式

在管理页“设置备份”中选择：

- **连接自己的 AI 服务**：填写兼容的聊天接口地址、模型和密钥；扫描识别还需模型支持图像。调用费用由自己的服务账户承担。每次处理前核对发送范围；远端结果不明时，插件不会自动重发。不能把可配置地址理解为所有服务商与模型均已兼容。
- **导出 Codex 任务后导入结果**：在导入页选择范围，导出任务文件及配套附件。让 Codex 按任务处理，再把返回的 JSON 导入同一个题库，保留原任务编号。结果仍先进入待核对区；来源文件已变化时需重新生成任务，不能套用旧结果。文件导出／导入本身不调用 AI，也不自动创建 Codex 聊天；实际处理使用自己的 Codex 访问权限和计费安排。

用自然语言组卷时，也遵循所选方式。Codex 模式会导出组卷条件任务；将返回的条件 JSON 粘回原输入框，再点击“梳理组卷条件”，检查表单和预览后保存。

AI 可以辅助识别结构、分类、匹配答案和形成解析草稿。没有来源答案的题不会因为 AI 能推理就自动获得确定答案；AI 建议和用户修订保留相应标识。插件不自动联网搜答案，也不默认读取整个 Obsidian 仓库。

## 题目管理、原卷和条件组卷

管理页可重命名题库、搜索和修改题目、停用题目、查看来源与修订记录，以及批量更改知识点名称。更改为已有名称会合并分类，不抹掉学习记录。

用户也可以在 Obsidian 中编辑生成的题目笔记。保留笔记中的身份记录，随后点击“检查题目笔记的外部修改”，核对差异后再采用。新练习使用已接受的修订；旧试卷和作答快照继续保留当时的内容。

**保存完整原卷前，整批候选题必须全部通过核对。** 用户还需对照原件确认总题数、顺序、图表和答案完整。已有的逐题分值保留；原资料未给出的时长或分值应注明是本次练习设置。卷头总分与逐题合计不同会分别展示，不静默折算。

条件组卷只使用当前题库可用且未停用的题目，可按知识点、题型、来源、错题、未答题或收藏筛选。题目不足时显示缺口，不自动放宽条件或编造新题。先预览，再保存；保存后冻结题目、顺序、答案和计分规则。

多选题支持两种计分方式：

- 全部选对才得分，少选或错选均为零分。
- 没有错选时，按命中正确项的比例给分；有错选或未作答均为零分。

取得部分分数仍按未完全答对进入错题本。模考交卷后才更新学习统计；未答题计零分并单独列出，不计为已答错题。已交卷的作答可分别回顾。

## 错题与巩固复习

错题本继续采用“答错加入、完整答对移出”，历史错误次数保留。巩固复习是独立安排：一次答对离开错题本后，题目仍可能在以后再次出现。

巩固按题库主动开启。当前采用 1、3、7、14、30 天的间隔阶梯；到期答对才延长间隔，提前重复答对不推进安排。答错或标记“这次蒙对了／仍需巩固”会回到短间隔。

旧学习记录只有在用户选择加入后才进入队列。开始一轮时可选择到期题量，也可暂停巩固。管理页支持明确确认后将选定已学题目重设为 24 小时后复查，不增加作答次数。产品不设置连续打卡或强制每日任务，也不承诺考试通过率。

## 电力题库兼容与旧数据迁移

兼容内容包保留 1433 道电力交易员四级题目：单选 704、多选 351、判断 378，按 22 个知识域及“未归类”组织。原有判题、错题、收藏、断点、统计和“题库／模考／统计”三个一级入口继续保留。

四套现有真题为 2026 年 6 月 26 日 A 卷、B 卷，6 月 30 日卷和 7 月 18 日卷，每卷 170 题。前三卷为 100 单选、30 多选、40 判断，逐题合计 100 分。7 月卷为 100 单选、20 多选、50 判断，逐题合计 95 分，卷头标注 100 分；插件按逐题分值计分。原有 120 分钟是沿用的练习设置，不能由个人实际用时推断为官方限时。原有两套样卷和五套模拟卷仍待映射，保持未开放状态。

检测到旧版学习数据时，插件先保存备份，再迁移已有题目身份、错题、收藏、累计统计、断点和仍保存的考试快照。旧版只保留最近 500 条活动明细及每卷最近一次快照，已经覆盖的历史无法补回。遇到无效或冲突数据时需核对，不用空数据覆盖。

这些是当前迁移代码的行为，不代表所有用户仓库或设备已完成升级验收。新用户可主动添加内置内容包，不必先用电力题库才能建立自己的题库。

## 数据保存、备份和同步

默认资料目录位于自己的 Obsidian 仓库内：

| 位置 | 保存内容 |
|---|---|
| `易记题库/题目/` | 用户题库的可读题目笔记 |
| `易记题库/资料/` | 选入的来源文件、来源索引、待核对草稿、整理任务和附件 |
| `易记题库/记录/` | 分设备保存的题库与学习记录，以及上一份有效副本 |
| `易记题库/备份/` | 完整备份、内容导出和旧版学习数据备份 |
| Obsidian 的插件数据 | 当前题库和 AI 服务等偏好设置 |

“完整备份”包含学习记录、修订、试卷快照、必要题图、原资料及未完成整理任务。内容导出可以去掉学习记录。两类导出文件都从“从备份恢复”入口读取，不使用普通题库 JSON 导入。

恢复前先检查文件并显示范围，再与当前数据合并；不同内容的同路径文件或记录不会静默覆盖。工作区备份需在相同题库根目录恢复。

密钥不写入题目、导出包或备份。宿主具备安全存储能力时使用该存储；否则仅在当前会话持有密钥。插件不自建账号、云端数据库或遥测服务。

**删除题库时，需要输入准确名称并确认范围。** 插件先保存并回读完整备份，再写入删除标记，使题库退出正常使用列表并避免旧记录自动恢复。原资料、保留的数据、已有备份和其他设备已经存在的副本不会自动清除。恢复已删除题库时会建立一个新题库副本。

仓库原有同步服务可能传输上述文件。发布负责人于 2026-11-05 确认 iOS 与 iCloud 手动验收通过；Android 核心流程在 Android 16／Obsidian 1.15.0 模拟器中完成。该结果不代表所有设备或同步服务均兼容。换设备前应确认来源资料和必要附件已到齐。

公开仓库仅包含插件代码及已授权公开的结构化内置题包。原始 `Study_Vault`、真题 PDF、本机 `.obsidian` 配置、内部产品文档，以及用户导入的题库和 AI 任务文件，不属于这次公开内容。

## 本地开发

要求 Node.js 20.19 或更高版本。

```bash
npm install
npm run verify
npm run install:local
```

本地安装脚本把构建文件复制到本项目的 `.obsidian/plugins/yiji-study/`，不会自动启用插件，也不代表公开发布。部分浏览器检查会用独立临时配置启动本机 Chrome；真机和真实同步需单独验收。

旧电力题包的 Markdown 真源位于 `Study_Vault/电力交易员StudyVault-题型版/`。完整的 20 个旧题源文件存在时，原题库加载流程可合并内置新增题。重新生成内置题包还需新增目录中的 11 个测验 Markdown、四份原始 PDF，以及 Poppler 的 `pdftotext`。`npm run content:generate` 核对原卷题号及题目内容；普通构建和测试使用已生成数据。用户自定义资料走运行时导入流程，不执行旧题包生成命令。

```bash
npm run dev                     # 监听源码并构建
npm test                        # 领域、导入、存储和界面等检查
npm run check                   # TypeScript 检查
npm run lint:obsidian           # 插件规范检查
npm run build                   # 生产构建
npm run check:ui                # 界面契约扫描
npm run check:mobile-layout     # 浏览器中的窄屏布局测量
npm run check:exam-ui           # 浏览器中的作答流程回归
npm run verify                  # 开发验证集合
npm run verify:release -- 0.2.0 # 对照本地候选版本声明检查发布文件
```

推送与 `manifest.json` 版本完全一致的 Git 标签后，GitHub Actions 会验证并发布 `main.js`、`manifest.json`、`styles.css` 和 `SHA256SUMS.txt`。本地检查通过不会自动发布版本。
