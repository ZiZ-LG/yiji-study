# 易记 / Yiji Study 0.2.0

易记现在可以用自己的考试资料建立题库：导入、核对、组卷、刷题和间隔复习都在 Obsidian 中完成，保留原有内置电力题库与四套真题。

## 新增

- 多个独立题库，支持手工创建和修订单选、多选、判断题，分开保存学习进度、错题和收藏。
- 导入 PDF、Word 和结构化文本，匹配独立答案文件；扫描资料可导出 Codex 任务或交给用户选择的兼容 AI 服务处理。
- AI 结果先进入待核对区，保留题目、答案和解析来源。缺答案、冲突及缺图不自动猜补或确认。
- 按知识点、题型、来源和学习状态组卷，支持原卷、冻结考试快照、计时交卷与间隔巩固。
- 完整备份保留学习记录、来源资料、题图和历史；内容导出恢复为从零开始学习的新副本。外部笔记修改先核对，再形成修订。

## 稳定性

- 新整理文件出现空写入时，保留并核对恢复副本，再进行一次受限恢复；已有内容或冲突不会因此被覆盖。
- 大备份导入不再把完整 JSON 放入手机编辑框，避免页面长时间卡顿；文件校验和恢复仍使用完整内容。
- 旧数据迁移保留备份，原有学习记录与考试快照按原规则保留。

## 更新与验证

在 Obsidian“设置 → 第三方插件 → 检查更新”中更新 **Yiji Study**；BRAT 用户也可检查更新。升级前保留仓库备份。手动安装仅替换 `main.js`、`manifest.json`、`styles.css`，不要删除 `data.json` 或题库目录。

本地 134 项自动测试通过，1 项可选容量测量跳过。Android 16／Obsidian 1.15.0 模拟器覆盖导入、核对、编辑、离线练习、后台考试及空仓恢复；8.86 MB 备份恢复后 79 项对账通过。iOS 与 iCloud 由发布负责人于 2026-11-05 手动验收并确认通过。
